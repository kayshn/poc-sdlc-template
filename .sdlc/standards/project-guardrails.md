Rules specific to this project. `.sdlc/standards/engineering-guardrails.md` holds the rules that
come with the SDLC template and apply to every project using it; this file holds the rest.

Numbered `P<n>` so a review can cite one without ambiguity — `G` ids always mean the standard.

- **P1**: <a rule this stack needs. Say what to do, and what it costs to ignore.>
- **P2**: <another.>

Two things make a rule here worth having: it is specific enough to be breached in an obvious way,
and a reviewer can tell from the diff alone whether it was. A rule that needs context the reviewer
does not have will be cited when it is cheap and skipped when it is not.
